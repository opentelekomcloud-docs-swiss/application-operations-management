Connecting Environments
=======================

You can use ICAgents to report CCE container metrics and ECS metrics to AOM.

Connecting CCE Container Metrics
--------------------------------

By default, an ICAgent is automatically installed when you apply for a CCE cluster. The ICAgent automatically reports CCE container metrics to AOM.

Connecting ECS Metrics
----------------------

After :ref:`you install an ICAgent <aom_02_0012>` on an ECS, the ICAgent automatically reports ECS metrics to AOM.
