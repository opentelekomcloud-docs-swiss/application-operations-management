Connecting Open-Source Monitoring Systems
=========================================

This function is suitable for customers who have self-built Prometheus servers, but need Prometheus storage availability and scalability through remote write.

Procedure
---------

#. On the menu bar, choose **Monitoring Center**.
#. In the navigation pane, choose **Access Center**.
#. In the **Open-Source Monitoring** panel, click the **Prometheus for Remote Write** card.
#. In the displayed dialog box, :ref:`create a Prometheus instance for remote write <mon_01_0070>`.
