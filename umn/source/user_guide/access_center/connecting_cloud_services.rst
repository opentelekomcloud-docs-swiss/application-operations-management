Connecting Cloud Services
=========================

Connect cloud service metrics, such as the CPU usage, memory usage, and health status.

Procedure
---------

#. On the menu bar, choose **Monitoring Center**.
#. In the navigation pane, choose **Access Center**.
#. In the **Cloud Services** panel, click a target cloud service card.
#. In the displayed dialog box, select a target cloud service and click **Confirm** to connect the cloud service metrics to the created :ref:`Prometheus instance for cloud services <mon_01_0067>`.
