Prometheus Monitoring
=====================

AOM is fully connected with the open-source Prometheus ecosystem, monitors different types of components, provides multiple ready-to-use dashboards, and supports flexible expansion of cloud-native component metric plug-ins. After installing the Prometheus plug-in on the CCE console, you can connect metric data to AOM for unified management.

Precaution
----------

System instances cannot be deleted.


Prometheus Monitoring
---------------------

#. In the navigation pane, choose **Prometheus Monitoring**.

   The Prometheus instance list displays information such as the instance name, instance type, and creation time in real time.

#. Enter an instance name in the search box and click |image1| to search.

#. Click the instance name to go to the details page and view information such as credentials.

   -  In the **Credential** area, the basic information and credential of the instance are displayed.

      -  By default, the AppKey is hidden. To show it, click |image2|. |image3| or |image4| reflects the status of the AppKey.
      -  Click |image5| on the right of the Prometheus configuration code to copy it to the corresponding file.
