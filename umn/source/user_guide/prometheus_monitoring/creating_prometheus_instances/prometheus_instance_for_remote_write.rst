Prometheus Instance for Remote Write
====================================

This type of instance is recommended when Prometheus servers have been built. The availability and scalability of Prometheus storage need to be ensured through remote write.

Creating a Prometheus Instance for Remote Write
-----------------------------------------------

#. On the menu bar, choose **Monitoring Center**.
#. In the navigation pane on the left, choose **Prometheus Monitoring** > **Instances**. On the displayed page, click **Add Prometheus Instance**.
#. Set the instance name and instance type.

   .. table:: **Table 1** Parameters for creating a Prometheus instance

      +-----------------------------------+------------------------------------------------------------------------------------------------------------------------------------------------------+
      | Parameter                         | Description                                                                                                                                          |
      +===================================+======================================================================================================================================================+
      | Instance Name                     | Prometheus instance name.                                                                                                                            |
      |                                   |                                                                                                                                                      |
      |                                   | Enter up to 100 characters and do not start or end with an underscore (_) or hyphen (-). Only letters, digits, underscores, and hyphens are allowed. |
      +-----------------------------------+------------------------------------------------------------------------------------------------------------------------------------------------------+
      | Instance Type                     | Type of the Prometheus instance. Select **Prometheus for Remote Write**.                                                                             |
      +-----------------------------------+------------------------------------------------------------------------------------------------------------------------------------------------------+

#. Click **OK**.
