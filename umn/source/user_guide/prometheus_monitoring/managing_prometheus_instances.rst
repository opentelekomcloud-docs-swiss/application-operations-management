Managing Prometheus Instances
=============================

You can view the names, types of Prometheus instances in the instance list and modify and delete them as required.

Procedure
---------

#. On the menu bar, choose **Monitoring Center**.

#. In the navigation pane on the left, choose **Prometheus Monitoring** > **Instances**. In the instance list, check the created Prometheus instances and perform the operations listed in :ref:`Table 1 <mon_01_0072__en-us_topic_0000001632737381_table1679219139498>` if needed.
