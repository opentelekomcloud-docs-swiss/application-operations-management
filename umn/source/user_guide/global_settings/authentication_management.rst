Authentication Management
=========================

An access code is an identity credential for calling APIs. Create an access code for setting API call permissions. The setting takes effect for the entire AOM service.

Precautions
-----------

You can create up to two access codes.

Creating an Access Code
-----------------------

#. Log in to the AOM console.
#. In the navigation pane, choose **Global Configuration**.
#. In the navigation pane on the left, choose **Authentication**. Click **Add Access Code**.
#. In the dialog box that is displayed, click **OK**. The system automatically generates an access code.

------------------

After an access code is created, you can perform the operations listed in :ref:`Table 1 <en-us_topic_0000002483058966__en-us_topic_0000001289745460_en-us_topic_0169698339_table15831736105910>`.
